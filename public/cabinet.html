From one cabinet to cutting

Cabinet starter defaults. 18 mm carcass, doors and shelves; 6 mm captured back; 6 mm deep grooves; raised dado bottom; one adjustable shelf; two overlay doors. This is a practical starting construction, not a universal specification. Use measured board thickness, test the 0.2 mm groove clearance and use suitable glue/assembly. Edgebanding deducts material from selected core edges while preserving finished cabinet sizes; enter actual band thickness, or zero to disable.

Wall cabinets. Select Wall cabinet for 320 mm starting depth, two adjustable shelves and bottom handles. Both styles support open/no-door fronts and two rails or a full top. Wall handles offer bottom free-edge or bottom-centre only. Wall bottom is calculated from counter height plus the gap; its height extends to the shared top-above-floor target. Feet and suspension-hardware holes are excluded.

Kitchen height targets. Finished counter height includes the worktop. Base carcass height = counter height − worktop thickness − foot mounting height + bottom lift (if dado-fixed). Foot height is measured to the bottom-panel underside and applies even when foot drilling is off. Wall bottom = counter height + gap. Wall carcass height = shared top-above-floor target − wall bottom. These targets are saved with project defaults for future tall-cabinet alignment. Legacy projects acquire targets that preserve their existing carcass sizes.

1. Cabinet. Configure dimensions and hardware, or choose Apply cabinet starter defaults. The preset keeps name, body dimensions, material choices, machine travel and feeds. Undo restores the previous settings. Select any ⓘ for a full explanation.

2. Parts. One-side flat machining is on by default. The machining face is the inside/groove/hinge-cup face. Through holes are made from that face too. Blind-feature depths and hardware geometry are preserved. Each panel’s face-up instructions are shown and exported.

3. Nesting. Material and thickness determine sheet groups. Doors share carcass material by default; turn that off for a different finish. In one-side mode, every part must have its listed machining face UP and suitable show face DOWN. Check the board’s finish on each side before using a mixed layout. Grain rotation remains a separate choice.

4. Required bits. The Toolpaths summary lists diameters, jobs and minimum usable reach. Use suggested bits selects a simple geometry-compatible set, usually a 3 mm end mill and 2.5 mm pilot drill for individual blanks. Nested sheets use one small centre-cutting end mill (normally 2.5 mm) for every flat operation. Install actual matching tools; the app cannot check your tool inventory. Hinge cups are circular-milled, so a 35 mm boring bit is not required.

Travel sequencing. A deterministic nearest-next/local-swap heuristic reduces safe travel within each tool/setup and retains a better original order when found. It does not guarantee a mathematical optimum. Cutting paths, pass depths and climb direction stay intact; feature machining remains before tabbed contours, and XY rapids remain at Safe Z. Tool changes and probing remain separate stage boundaries.

Flat setups. G54 X0/Y0 is the lower-left of the current sheet or oversized blank; Z0 is stock top. In one-side mode there is no stock flip. Features finish before the final profiles; four tabs retain each part. Stop for manual tool changes and re-zero Z. Through cuts require a sacrificial spoilboard.

Adjustable feet. Choose a generic rectangular, triangular or centre-fixing pattern and two front or four corner positions. Enter the physical plate’s actual pitch and screw pilot dimensions; these are not manufacturer-specific templates. Through feet holes are on by default and stay in the main single-face setup. Switch this off for blind underside pilots and their separate post-cut setup. Two front feet require independent rear support.

Optional edge pilots. Assembly screw holes add matching side clearances and bottom/rail edge pilots. Edge programs are a separate export: finish flat machining, cut out and remove tabs, then stand the named finished edge up in a secured fixture. The setup guide gives its datum/direction. They are not included in flat or sheet programs.

Manual tool changes. Operation tools use T1 for small holes, T2 for dados and T3 for hinge cups and contours. One sheet program pauses to fit each new tool and attach the probe, probes with G38.2, corrects G54 Z with G10 L20 P1 using your measured plate thickness, then pauses to remove the plate and clip. Manual routers must be switched off for changes and on before resuming after plate removal. Set real probe location, depth, feed and change height. Keep stock and G54 XY fixed. The cutting preview excludes probing motions. Separate stage files are available if you prefer to re-zero manually between files. Use either the combined program or its stage alternatives, never both. See the V1 tool-change guidance.

Cutting settings. Feed, RPM, pass depth and workholding depend on the actual cutter, material and machine. The app’s values are editable examples. Consult the tool maker’s material-specific cutting data, then verify the actual setup. The preview shows commanded motion, not stock removal or clamp/holder collision simulation. No program is sent to a machine.

Projects. Autosave is local to this browser. Save project JSON for backup. Earlier workbench files acquire the new one-side setting without changing dimensions, hardware or machine travel. Original two-face mode remains available by switching One-side flat machining off.
