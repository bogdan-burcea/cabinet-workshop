Your kitchen, in the browser

Add items from the catalog. Select an object to edit its dimensions, wall and position. Drag in plan with 10 mm snap; hold Alt to select a base below a wall cabinet.

Projects: your latest layout is automatically stored in this browser on this device. Download a project JSON to keep a separate copy or transfer it. Desktop v0.1/v0.2 and earlier browser project files also open here. Projects with new cabinet types use the current browser format. Project files are not yet saved to an online account.

Worktops: Generate worktops replaces the current slabs with straight runs over adjoining base cabinets and compatible dishwasher bays. Undo restores the previous set. Regenerate after moving cabinets; slabs are editable snapshots.

Blind corners: choose the blind side, blind width and return clearance. The fixed blind front covers that side; one access door covers the remainder. Review the return-gap and door-access checks. Room → Load corner example shows a complete L-shaped layout.

Finishing: select a cabinet, open Finish in the catalog, then choose After or Before and add a filler or end panel. These are independent pieces. Generated worktops include compatible adjoining finishing pieces.

Sinks and hobs: select a worktop or a base cabinet with a worktop, then add the fixture from Appliances. Cutout size, overall size and body space are separate. Enter the manufacturer’s installation dimensions; the initial sizes are generic. This release supports rectangular, square-corner through-cutouts only. Show cutouts hides fixture models so you can inspect the openings. STEP keeps each worktop as one solid. CSV cutout schedule lists the opening geometry.

Openings: the dashed area is an editable inward clearance zone. Door zones are rectangular, rather than precise swing arcs. Window sill height allows cabinets beneath the opening.

Dados & drilling: select a cabinet, then configure captured back grooves, bottom dados, drawer bottom grooves, screw joints, five-height shelf pin banks, hinge/runner presets, handles and foot plate holes. Enable common drilling selects a starting set for that cabinet. Existing projects remain unmachined until enabled. Room → Load dados & drilling example demonstrates the features. Invalid bores and groove collisions are rejected. Lower drawer wall heights may need reducing when the cabinet bottom is lifted.

Nest & cut: groups rectangular parts by editable material and exact thickness. Set stock sizes, edge margin, part spacing and rotation; review the sheets, then export PDF, DXF or flat STEP solids. A per-sheet STEP button exports at that sheet’s own origin. Rename the initial material groups to your actual materials. Parts that do not fit block export. Layouts use finished dimensions; cutter compensation and toolpaths are not included.

Exports: STEP and CSV include cabinets, worktops, fillers and end panels. Appliance placeholders and opening frames are excluded. Dados & drilling adds optional cabinet machining. STEP contains actual bores and grooves. DXF uses face/depth layers; PDF and machining CSV include setup information. Rounded cutout corners and CNC toolpaths are later stages.

Updates: reopen or refresh this same link for a new release. Your local autosave remains. New and Open keep your previous layout available through Undo.
